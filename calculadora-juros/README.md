# Calculadora de Juros

Projeto separado da funcionalidade de simulação financeira do FinanceAcademy.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Escolha o tipo de investimento, informe o aporte, o tempo e a taxa.
4. Clique em **Calcular rendimento**.

## Funcionalidades

- Simulação de juros compostos.
- Opções de Poupança, CDI e LCI/LCA.
- Validação dos campos.
- Histórico salvo no navegador com `localStorage`.
- Limpeza dos campos e do histórico.

## Tecnologias

- HTML
- CSS
- JavaScript
- Bootstrap 5

**Observação:** o histórico fica salvo no armazenamento local do navegador utilizado. A taxa mensal de referência do CDI está definida no código como 0,83%, conforme a implementação original do projeto.
